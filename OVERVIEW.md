# Overview

A fork of the Vercel AI SDK — a library for building AI-powered streaming text and chat UIs in React, Svelte, Vue, and Solid. It provides React Server Components support for generative UI, first-class integrations with OpenAI, Anthropic, Mistral, Perplexity, AWS Bedrock, Azure, Google Gemini, Hugging Face, Cohere, LangChain, Replicate, Ollama, and more, and runs on Node.js, Serverless, and Edge runtimes.
